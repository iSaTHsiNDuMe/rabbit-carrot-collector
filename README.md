# Rabbit Carrot Collector

A Unity 6 URP woodland prototype built in a LEGO style. The main scene includes a studded forest, carrot garden, creek and bridge, two rabbit prefabs, two hunter prefabs, and a burrow reunion area.

## Open the project

1. Add this repository folder to Unity Hub and open it with Unity **6000.6.4f1**.
2. Let Unity restore the packages in `Packages/manifest.json`.
3. Open `Assets/Scenes/RabbitSurvivalLEGO.unity` by itself in the Unity Editor.

The scene contains environment geometry, colliders, patrol waypoints and trigger volumes. Character controls, hunter AI, the win condition and the coursework tutorial demos are not implemented in this snapshot.

The environment and brick-style character assets were produced with AI-assisted Unity editor tooling.
